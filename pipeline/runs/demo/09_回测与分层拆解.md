# 回测与 IC 分层 · 单日拆解

> 样本日 **2021-01-19**（该日 IC 在全部 65 个调仓日中处于中位）｜持有 21 个交易日｜分 5 组

## 1. 这一天的截面长什么样

- 当日有因子值的股票：**173** 只
- 其中能算未来 21 日收益（未退市、数据完整）：**173** 只
- 因子值分布：min 0.000 / P25 0.250 / 中位 0.500 / P75 0.750 / max 1.000
- 因子值范围 0.000 ~ 1.000：这是**截面百分位（0~1）**，不是原始残差
  因为 S5 已经做过 `winsorize → 行业+市值中性化 → 截面 rank`

## 2. IC 是怎么算的

```
IC = spearman(因子值, 未来21日收益)   # 每个调仓日算一次，得到一个序列
```
- 程序算的 IC：**+0.0234**
- 手算（秩 → 皮尔逊）：**+0.0234**（差 3.47e-18，说明 spearman 就是秩相关）
- 复现校验：`corrcoef(rank(factor), rank(fwd_ret))` 与程序值一致 ✅

**注意事项**：IC 是逐日/逐期截面相关，不是时序相关；它衡量的是「同一天里，因子排名和未来收益排名有多像」，不是「因子涨收益就涨」。

## 4. 分层收益与多空

```
每组收益 = 该组所有股票未来21日收益的等权平均
多空     = L5 平均收益 - L1 平均收益
```
| 组 | 平均因子值 | 平均未来21日收益 | 收益名次 |
|---|---|---|---|
| L1 | 0.0959 | +2.558% | 1 |
| L2 | 0.2965 | -1.212% | 4 |
| L3 | 0.4971 | -3.476% | 5 |
| L4 | 0.6977 | +1.415% | 2 |
| L5 | 0.9012 | +0.225% | 3 |

- 多空（L5 − L1）= **-2.333%**
- 单调性（程序判定）= **False**（判定标准：五组收益严格递增或严格递减，不含相等）

## 4b. 全期分层统计（65 个调仓日）

单日那张表只能说明「这一天怎么算」，不能说明「因子好不好」。把所有调仓日摞起来才有意义：

| 组 | 每期均值 | t 值 | 胜率 | 5.5年累计净值 |
|---|---|---|---|---|
| L1 | -0.192% | -1.11 | 43.1% | 0.877 |
| L2 | -0.267% | -1.92 | 41.5% | 0.837 |
| L3 | -0.272% | -1.96 | 38.5% | 0.834 |
| L4 | +0.120% | +0.77 | 44.6% | 1.076 |
| L5 | +0.194% | +1.47 | 58.5% | 1.130 |

- 全期多空每期均值 **+0.386%**，t = +1.80
- 全期各组均值（%）：-0.192 → -0.267 → -0.272 → +0.120 → +0.194
- 按全期均值判定单调性：**False**
  → 单日不单调是常态，**要看的是一段时间的平均是否单调**，因为单期噪声远大于信号
  → 本例就是「两端有效、中间无序」：L5>L1 但 L2 比 L1 更低。这种形态下多空能赚钱，但**不能按组递推**（比如「买 L4 比 L3 好」就不成立）。

**为什么单日和全期会打架**：单日 200 只票，收益噪声 σ≈8%，均值差只有 0.1% 量级，信噪比极低；摞 60 期后噪声按 √n 衰减，才有统计意义。这也是为什么不能拿一天的分层图下结论。

## 5. 多空净值是怎么累起来的

```python
nav[0] = 1
for 每个调仓日: nav.append(nav[-1] * (1 + spread))   # spread = L5 - L1
年化 = (1 + mean(spread)) ** (252/调仓间距) - 1
夏普 = mean(spread) / std(spread) * sqrt(252/调仓间距)
回撤 = min(nav / cummax(nav) - 1)
```

本次结果：多空年化 **4.74%**、夏普 **0.775**、最大回撤 **-5.28%**

**这里有个必须说清的假设**：净值是「每期把多空收益按复利再投入」，隐含**可无限做空、无保证金约束、无融券成本**。真实 A 股做空受限，多空曲线只能当作因子强度的度量，不能当作可实现收益。

## 6. 换手与成本

```
持仓 = L5 组 + L1 组（约 40% 的股票）
单边换手 = |本期持仓 XOR 上期持仓| / |本期持仓|
每期成本 = 单边换手 × 2 × 单边费率（买卖各一次）
```

实测：单边换手 **45.8%**，每期成本 **0.137%**，年化毛利 4.74% → 扣费后 **3.03%**

**换手算法的局限**：这是「名字换手」（有多少只票换了），不是「权重换手」。等权组合下两者接近，但如果按市值加权或因子加权，必须改成权重口径。另外 40% 的持仓意味着一半资金在多头、一半在空头，实际资金占用是 2 倍名义。

## 7. 三个容易被忽略的偏差

| 偏差 | 这里怎么处理的 | 还差什么 |
|---|---|---|
| 前视 | 因子只用 ≤ ann_date 的数据；G3.1/G3.2 门禁 | 已处理 |
| 同日成交 | 用 **t 日收盘价**买入、t+21 收盘卖出 | 严格应 t+1 开盘，或假设收盘集合竞价能成交 |
| 幸存者偏差 | 股票池来自当前面板，退市股不在里面 | 本次是合成数据无退市；真实数据必须补退市股 |
| 可交易性 | 未剔除停牌、涨跌停 | **未处理**，真实回测必须加 |

## 8. 一句话总结

IC 回答「排序准不准」，分层回答「单调不单调」，多空回答「价差有多大」，换手+成本回答「拿不拿得到」。四个都过才算能用；缺一个，前三个都可以是假的。
