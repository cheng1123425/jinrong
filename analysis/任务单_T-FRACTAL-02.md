# 任务单 T-FRACTAL-02

**任务名称**：分形方法样本外检验（2024 vs 2025，日线）
**负责人**：执行 Agent（按因子建模师 × 小波顾问的方法执行）
**派发**：项目指挥官
**依赖**：无

## 目标

用全量日线数据，检验 6 种分形/形态方法在 **2024（样本外）** 与 **2025（样本内）** 的表现是否一致。
重点回答：某个方法在 2024 有效、2025 是否仍有效；若两年符号相反，明确判定为"不稳定"。

## 输入

| 项 | 路径/说明 |
|---|---|
| 原始数据 | `E:/全量历史数据-/stock-trading-data-2025-12-23N.zip`（5782 只，日线，含逐日名称） |
| 现成缓存（可复用，省去重新解压） | `analysis/panel2425.pkl`：`dict[code] = {dates, name, o, h, l, c, pc, v, fmv}`，2024-01-02 至 2025-12-23 |
| 可复用指标函数 | `analysis/fractal_lab.py`：`path_roughness` / `mfdfa_width` / `hurst_rs` / `dtw_dist` / `shape_code` / `code_match` / `TPL` / `auc_score` |
| 可复用小波函数 | `analysis/pattern_similarity.py`：`wave_features` / `wave_similarity` |

> 用不用这些资产由你决定，但不得改变取值口径。

## 口径（必须一致）

- ST 识别：名称由非 ST 变为含 ST 的首个交易日；年初已 ST 的不计入当年新增
- 买点：当年 10-15 ~ 11-07 的首个交易日收盘
- 特征窗口：买点前 120 根日线（约半年）
- 持有：20 个交易日
- 标签：持有收益 ≥ 30% 记正样本
- 模板：`TPL`（下跌 40 / 上涨 40 / 回落 30 / 突破 10，共 120 根）

## 验收标准

1. `python analysis/out_oos/fractal_oos.py` 可运行，退出码 0
2. `result.json` 与 `report.md` 的数字一致
3. 分年（2024 / 2025）给出 7 个方法各自的：Spearman、p 值、AUC、Top10 命中率
4. 明确标注每年的**样本数与正样本率**
5. 给出**跨年符号一致性表**（同一方法 2024 与 2025 的 Spearman 符号是否相同）
6. 若报告了 2024+2025 合并样本的结果，必须检查是否为年份混杂（正样本率差异 / Simpson 悖论），并明确说明合并显著性是否可信
7. 特征只使用买点之前的数据，标签使用买点之后 20 日
8. 结论必须明确写出：哪些方法跨年稳定、哪些不稳定、哪些无效
