# 任务单 T-FRACTAL-01

**任务名称**：参考 K 线形态模板，做多种分形方法对比实验
**派发人**：项目指挥官
**执行**：因子建模师（结构类方法）＋ 小波顾问（多尺度/分形类方法）
**依赖**：无（模板由文字描述构造，不依赖具体个股）

## 目标
给定一个由你描述构造的「下跌 → N 字上涨 → N 字回落不创新低 → 突破」60 分钟模板，
用 6 种分形/形态方法分别度量 2025 年 ST 股在 10 月买点前的相似度，
看哪一种（如果有）能事前筛出后续大涨的样本。

## 输入
- 数据：`tmp60/60分钟/*.csv`（2025 全年，243 天 × 4 根）
- 样本：2025 年新增 ST 126 只
- 买点窗口：2025-10-15 ~ 2025-11-07 首个交易日
- 标签：买点后 20 个交易日收益 ≥ 30% 记为正样本

## 交付物
| # | 路径 | 形态 |
|---|---|---|
| 1 | `analysis/fractal_lab.py` | py，含 6 种方法与自检 |
| 2 | `analysis/分形方法对比实验.md` | md，结果表 + 验收 |

## 验收标准
1. 6 种方法均可独立运行，自检通过（模板自匹配=1、随机数据不误报）
2. 每种方法给出：Spearman(方法, 20 日收益)、AUC、Top-10 命中率、信号数
3. 明确标注样本量、正样本数、AUC 置信区间
4. 结论必须写「哪几种有效/无效」，不允许模糊表述
5. 全部指标只用买点前数据，无前视

## 禁止事项
- 不许按结果调参数后只报最好的一组
- 不许把「收益≥30%」的标签信息用于构造特征
- 不许省略负样本

# 执行记录

## 方法清单（6 种）

| # | 方法 | 归属 | 度量对象 |
|---|---|---|---|
| M1 | Higuchi 分形维数 | 因子建模师 | 序列粗糙度 |
| M2 | MF-DFA 广义 Hurst 谱宽 | 小波顾问 | 多重分形强度 |
| M3 | R/S Hurst 指数 | 因子建模师 | 长程相关 |
| M4 | MODWT 跨尺度相似度 | 小波顾问 | 与模板的多尺度形状相似 |
| M5 | DTW 距离 | 因子建模师 | 与模板的路径对齐距离 |
| M6 | 形态符号编码匹配 | 因子建模师 | 分段涨跌方向一致性 |
| M0 | 已实现波动率 | 对照基准 | 证明"不是随便什么指标都有效" |

## 模板（先验构造，不使用 2025 标签）

```
0–39 根   : 1.00 → 0.88    下跌段
40–79 根  : 0.88 → 1.10    N 字上涨
80–109 根 : 1.10 → 1.02    N 字回落，不创新低
110–119 根: 1.02 → 1.08    突破
```

归一化后作为模板，长度 120 根（30 个交易日）。
