## 0. 先把问题定义清楚

原话是「60 分钟线走了一个自相似，分型分的一模一样」。这句话有三个无法直接计算的部分：

| 原话 | 问题 | 本规范的处理 |
|---|---|---|
| 自相似 | 相似到什么程度算相似？ | 给出相似度函数与阈值 |
| 分型 | 用哪种分型定义？ | 固定为三根 K 线的顶/底分型（含包含关系处理） |
| 一模一样 | 完全相同还是结构相同？ | 拆成"类型序列一致" + "幅度/间隔相似"两个条件 |

**定义（本规范的唯一口径）**：

> 在 t 时刻，取最近 K 个分型构成序列 S_now；在过去 L 个交易日的历史中寻找序列 S_hist。
> 若 `type_match(S_now, S_hist) == 1` 且 `shape_similarity(S_now, S_hist) ≥ θ`，则称 t 时刻存在"分型自相似"。

任何偏离这个定义的"看起来像"，都不进入检验。

## 1. 方案 A：分型序列匹配（因子建模师）

### A.1 包含关系处理

相邻两根 K 线若一根的高低点完全覆盖另一根，即存在包含关系，需合并，否则分型会被噪声打乱。

设当前趋势方向 `dir`（由前一个已确认分型决定：底分型后向上，顶分型后向下）：

```
若 K[i] 包含 K[i-1] 或 K[i-1] 包含 K[i]：
    向上趋势：high = max(high_i, high_{i-1})，low = max(low_i, low_{i-1})
    向下趋势：high = min(high_i, high_{i-1})，low = min(low_i, low_{i-1})
    用合并后的 K 线替换这两根
```

合并后得到"无包含序列" `B[0..M-1]`。

### A.2 分型识别

对无包含序列的每个内部点 i（1 ≤ i ≤ M-2）：

```
顶分型：B[i].high > B[i-1].high 且 B[i].high > B[i+1].high
        且 B[i].low  > B[i-1].low  且 B[i].low  > B[i+1].low
底分型：B[i].low  < B[i-1].low  且 B[i].low  < B[i+1].low
        且 B[i].high < B[i-1].high 且 B[i].high < B[i+1].high
```

**相邻同类合并**：若连续出现两个顶分型，保留高点更高的那个；底分型保留低点更低的。保证顶底交替。

### A.3 序列编码

取最近 K 个已确认分型（K=5），每个分型编码为三元组：

```
t_j     : 距今天数（用 60 分钟根数表示）
p_j     : 分型处的价格（顶用 high，底用 low）
type_j  : 顶=+1，底=-1
```

构造两个向量：
- **幅度向量** `amp = [|p_j - p_{j-1}| / p_{j-1}]`，长度 K-1
- **间隔向量** `gap = [t_j - t_{j-1}]`，长度 K-1

### A.4 相似度

```
type_match = 1  (若 S_now 与 S_hist 的 type 序列逐位相同)  否则 0
amp_sim    = cosine(amp_now, amp_hist)          # ∈ [-1,1]
gap_sim    = cosine(gap_now, gap_hist)
shape_sim  = 0.5*amp_sim + 0.5*gap_sim
```

### A.5 信号

```
若 type_match == 1 且 shape_sim ≥ 0.8：
    在"当前分型确认后的第一根 60 分钟 K 线收盘"发出信号
```

**信号必须落在分型确认之后**，不能用分型当根 K 线（当根还不知道它是不是分型）。

### A.6 参数冻结表（写死，不许事后调）

| 参数 | 取值 | 依据 |
|---|---|---|
| 数据周期 | 60 分钟 | 你的用法 |
| 分型窗口 | 3 根 | 标准定义 |
| 匹配分型数 K | 5 | 3 个幅度 + 4 个间隔，够区分又不至于样本枯竭 |
| 历史搜索长度 L | 120 个交易日（480 根） | 约半年 |
| 幅度相似阈值 | 0.8 | 余弦 |
| 间隔相似阈值 | 0.7 | 余弦 |
| 综合阈值 θ | 0.8 | — |
| 最小分型间隔 | ≥ 4 根 | 避免同段重复计数 |

## 2. 方案 B：多尺度形状相似（小波顾问）

### B.1 为什么加这一层

分型只看"拐点在哪"，不看"拐点之间怎么走"。两段分型序列可以完全相同，但中间一段是平滑推进、另一段是剧烈震荡。小波能把"形状"拆到不同尺度上比较。

### B.2 MODWT 分解

对 60 分钟收盘价序列（窗口 W=64 根）做 **MODWT（极大重叠离散小波变换）**，J=3 层：

- 选 Haar 或 db2；**归一化必须用 h/√2（即系数 1/2 形式）**，否则能量不守恒。
- 得到细节系数 `D1, D2, D3` 与近似 `A3`。
- 尺度对应：D1≈2 根（2 小时）、D2≈4 根（1 天）、D3≈8 根（2 天）；A3 是更粗的趋势。

> 用 MODWT 而不是 DWT：不下采样、系数与时间点对齐、平移不变，才能做"同位置对齐"的相似度比较。

### B.3 跨尺度相似度

对当前窗口与历史窗口，逐尺度计算相关系数：

```
sim_j = corr(D_j_now, D_j_hist)      j = 1,2,3
sim_A = corr(A3_now, A3_hist)
wave_sim = 0.15*sim_1 + 0.25*sim_2 + 0.30*sim_3 + 0.30*sim_A
```

**粗尺度权重更高**：形态的"轮廓"由低频决定，高频更多是噪声。若某尺度方差接近 0（死水），该尺度权重置 0 并重新归一。

### B.4 边界处理

- 每个窗口两端各丢弃 `L-1` 个系数（Haar 丢 1，db2 丢 3），只比较中段。
- 窗口必须完整落在 t 之前，**末端对齐 t-1**，不允许把 t 当根放进去。

### B.5 参数冻结表

| 参数 | 取值 |
|---|---|
| 小波 | Haar（无依赖实现）或 db2（有 PyWavelets 时） |
| 分解层数 J | 3 |
| 窗口 W | 64 根 |
| 权重 | 0.15 / 0.25 / 0.30 / 0.30 |
| 相似阈值 | ≥ 0.75 |

## 3. 方案 C：双确认融合（推荐）

单一方案都容易出假阳性，融合后用**两个独立视角同时确认**：

```
signal_A = 1 若方案 A 触发
signal_B = 1 若方案 B 触发
signal_C = signal_A AND signal_B
score_C  = 0.5 * shape_sim + 0.5 * wave_sim
```

只有 C 触发才视为"分型自相似"，且要求 `score_C ≥ 0.80`。

**预期效果**：信号数量会大幅减少（可能个位数）。这不是缺点——你本来就说"只有先蓄势后突破的才能从容建仓"，那本来就该是少数。

## 4. 防前视（最容易出错的地方）

| 风险 | 规则 |
|---|---|
| 用当根 K 线判断分型 | 分型必须由**其后一根**确认后才可用 |
| 用未来窗口做相似度 | 历史窗口末端 ≤ t-1 |
| 用全样本分位数定阈值 | 阈值写死在参数表，不许按结果调 |
| 用未来数据选"哪段最像" | 历史搜索只允许 `[t-L, t-1]` |
| 归一化用了全样本均值 | 用窗口内统计量 |

## 5. 检验方案（做完再看结果）

### 5.1 样本
- 2025 年新增 ST 123 只（已有名单），60 分钟数据 2025 全年。
- 2024 年用日线无法复现 60 分钟，**这是硬约束**：60 分钟库里只有 2025 年。所以本方案**无法做样本外**。

### 5.2 事件研究
```
对每个信号：
  T0 = 信号后第一根 60 分钟 K 线收盘
  收益 = close(T0 + 20 交易日) / close(T0) - 1
```
对照组：同期无信号的 ST 股（同一买入窗口）。

### 5.3 判据（预先写死）
| 项 | 门槛 |
|---|---|
| 信号数 | ≥ 30 才做统计；< 10 直接判"证据不足" |
| 胜率 | ≥ 60% |
| 中位收益 | ≥ 10% |
| 与对照组差 | ≥ 5pp |
| 单样本最大亏损 | 报告，不剔除 |

### 5.4 已知短板（提前说清）
- **无法样本外**：只有 2025 年 60 分钟数据。
- **样本极少**：双确认后可能 <10 个信号，统计不成立。
- **参数多**：K、L、θ、W、J 五个参数，过拟合空间大。

结论大概率是"证据不足"，但这比"看起来像"诚实。

## 6. 伪代码（可直接实现）

```python
def build_signal(bars, K=5, L=480, theta=0.8):
    # bars: [(date, time, o, h, l, c)]，按时间升序
    B = merge_inclusion(bars)              # A.1
    fr = find_fractals(B)                  # A.2：[(idx, type, price, t)]
    if len(fr) < K + 2:
        return None
    now = fr[-K:]
    best = None
    for end in range(len(fr) - K - 1, 0, -1):        # 历史窗口，末端 < 当前
        hist = fr[end - K: end]
        if hist[-1].t >= now[0].t - L:               # 限制在 L 内
            continue
        if not type_equal(now, hist):
            continue
        s = 0.5 * cosine(amp(now), amp(hist)) + 0.5 * cosine(gap(now), gap(hist))
        if s >= theta and (best is None or s > best[0]):
            best = (s, hist)
    if best is None:
        return None
    # 小波确认（B）
    w_now = modwt_features(closes[-64:])
    w_hist = modwt_features(closes_at(best[1]))
    ws = wave_similarity(w_now, w_hist)
    if ws < 0.75:
        return None
    return {"score": 0.5 * best[0] + 0.5 * ws, "hist": best[1]}
```

## 7. 两个专家的一致意见（也是警告）

> **因子建模师**：这套规则能把"分型一模一样"变成可计算的东西，但它的自由度很高。K 从 5 改到 4、θ 从 0.8 改到 0.7，结果就会变。所以参数必须在看到收益**之前**冻结，跑完不许回头调。
>
> **小波顾问**：MODWT 这部分我可以保证数学上正确（能量守恒、平移不变、对齐），但 64 根窗口只能分 3 层，粗尺度只剩不到 8 个有效系数，相似度估计的方差很大。样本少的时候，这个相似度本身就不可靠。
>
> **共同结论**：算法可以给，但以现有数据（仅 2025 年 60 分钟）**无法验证**。要做，必须先补 2023–2024 年的 60 分钟数据，否则只能得到"证据不足"。

## 9. 实测结果（2025 年 ST 样本，参数未调整）

实现：`analysis/pattern_similarity.py`（自检 8 项全过），扫描脚本 `analysis/run_pattern_all.py`。

### 9.1 信号密度

| 项 | 数值 |
|---|---|
| ST 样本 | 126 只 |
| 全年信号总数 | 818 个 |
| 平均每只 | **6.5 个** |

信号密度过高：126 只票一年出 818 个"自相似"信号，说明这个形态在 60 分钟尺度上**并不稀缺**。

### 9.2 关键窗口（10/15–11/07）

| 项 | 算法信号组 | 未筛选 ST 组（对照） |
|---|---|---|

| 胜率 | 59% | 69% |

**筛选后反而更差**：中位低 3.8pp，胜率低 10pp。

### 9.3 尾部

信号组前 10 名：+36.3%、+35.6%、+31.3%、+31.2%、+21.9%、+20.9%、+16.6%、+14.6%、+14.6%、+14.2%。

它确实覆盖到几只大牛股，但中位数被大量平庸样本拉低。这正是"事后能看到牛股、事前无法筛选"的典型表现。

### 9.4 单例复核

用 `sz300159`（上次 10 月有买点、+6.7%）测试：算法给出 6 个信号，全部落在 6–9 月，**10 月一个都没有**。即算法抓不到你实际买入的那一段。

### 9.5 结论（两位专家一致）

> **因子建模师**：规则可执行、逻辑自洽，但在真实样本上没有增量。信号太多说明阈值宽松，收紧阈值会进一步减少样本——而样本本来就不够。
>
> **小波顾问**：64 根窗口只能分 3 层，粗尺度有效系数不到 8 个，相似度估计方差很大；用它做"一模一样"的判定，本身就不可靠。
>
> **共同结论**：**证据不足，且方向为负**。按本规范实现的"分型自相似"在 2025 年样本里没有预测力，中位收益低于不筛选。不建议据此提前买入。

### 9.6 若要继续，唯一有意义的动作

补齐 2023–2024 年 60 分钟数据做样本外。在此之前，任何"调参数让它变好"的操作都是过拟合。
