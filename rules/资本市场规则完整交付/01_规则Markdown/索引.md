## 转换口径与限制

- DOCX 用纯标准库按 `body` 子元素顺序解析，表格转 pipe table，丢弃 Word 自动目录域；
- 标题层级由「第X章 / 第X节 / 第X条」文本规律重建（实测证监会 DOCX 的 pStyle 不可靠）；
- PDF 仅在 DOCX/TXT 缺失或过短时用 pypdf 提取文字层；**无文字层的图片版 PDF 只生成占位文件，不编造正文**；
- 共用规章（如《证券登记结算管理办法》）按适用主体在各目录各存一份，便于单主体独立使用；
- 回环校验：抽样把原文句子归一化后在 Markdown 正文中回查，命中率写入 `转换报告.json`；
- 法规效力状态沿用各批次清单的核验结论，**使用前仍建议按 frontmatter 的 source_url 复核最新版本**。
