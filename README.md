# jinrong

A 股研究与合规分析的工程仓库。分为四块：可复用的研报复现流水线、若干专家知识包、实盘策略的验证与合规审核记录、以及一套中国资本市场监管规则库。

## 目录

| 路径 | 内容 |
|---|---|
| `pipeline/` | **研报复现流水线**：8 阶段 + 26 条代码化门禁，PM 靠 `08_gates.json` 验收。入口 `pipeline/README.md` |
| `analysis/` | 策略验证报告与脚本：ST 戴帽策略的统计检验、分形方法横向对比、样本外检验、回测拆解 |
| `analysis/合规/` | ST 策略合规审核意见（规则映射 + 风险分级） |
| `rules/` | 资本市场规则库：91 份规则、4016 条条文，覆盖散户 / 游资 / 机构 / 私募 / ETF / 股东 / 公募基金 |
| `*.zip` | 打包好的专家包（合规检验官、因子建模师、小波顾问、量纲分析师、数模分析、市场分析、项目指挥官） |

## 流水线快速开始

```bash
cd pipeline
python src/run.py --demo --out runs/demo      # 合成数据跑通八阶段
python tests/test_gates.py                    # 11 个门禁反例测试
python src/run.py --owners                    # 谁负责哪一步
```

## 结论摘要（ST 策略验证）

- 戴帽集中在 4-5 月：2025 年 124 只新增 ST，70.2% 落在 4-5 月
- 戴帽当天中位 **-5.00%**（ST 跌停），这条最稳
- 「6 月 10 日见底」不成立：2025 年仅 7.4% 在 6 月见底，65% 在 5 月
- 形态规则筛出的 27 只，买点后 20 日中位 **-5.9%**、胜率 29.6%（筛完比不筛更差）
- 戴帽前 20 日 CAR 中位 **-12.09%**：跌在戴帽前就发生了，不是戴帽导致的
- 「稳赚 30%」不成立：P(≥30%) = 13.33%

## 声明

- 仓库内所有结论基于历史数据，不构成投资建议。
- 合规意见为风险筛查，非法律意见，且规则库未收录《证券法》全文与债券业务规则。
- 数据文件（`.pkl`）未入库，脚本需自备行情数据。
